🚀 How to Use
1️⃣ Clone the repository
git clone https://github.com/harsh2595/k8s-learning.git
cd k8s-learning
2️⃣ Start Kubernetes (example with Minikube)
minikube start
3️⃣ Apply configurations
kubectl apply -f <file-name>.yaml
4️⃣ Check resources
kubectl get pods
kubectl get services
